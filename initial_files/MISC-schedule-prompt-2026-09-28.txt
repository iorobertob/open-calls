=== 7. PRIVALOMA QR PATIKRA ===

Dekoduok QR kodus iš galutinio PDF IR iš JPEG failų:
```python
import numpy as np, cv2, pypdfium2 as pdfium
det = cv2.QRCodeDetector(); found=set()
def scan(img):
    ok, texts, _, _ = det.detectAndDecodeMulti(img)
    if ok: found.update(t for t in texts if t)
    th = cv2.threshold(img,200,255,cv2.THRESH_BINARY)[1]
    cnts,_ = cv2.findContours(th, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for c in cnts:
        x,y,w,h = cv2.boundingRect(c)
        if 150<w<800 and 0.8<w/h<1.25:
            t,_,_ = det.detectAndDecode(img[max(0,y-12):y+h+12, max(0,x-12):x+w+12])
            if t: found.add(t)
pdf = pdfium.PdfDocument(PDF_PATH)
for i in range(len(pdf)):
    scan(np.array(pdf[i].render(scale=3).to_pil().convert('L')))
for j in sorted(JPG_DIR.glob('*.jpg')):
    scan(cv2.imread(str(j), cv2.IMREAD_GRAYSCALE))
```
Palygink `found` su visų open įrašų url (unikaliais — keli įrašai gali dalintis vienu url). Trūkstant bent vieno — taisyk ir kartok.
